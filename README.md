# Limit Startup

#### 介绍
Limit Startup 是一个简洁、可个性化的浏览器起始页，支持搜索、壁纸、主题与账号偏好同步。

#### 大致功能
1. 切换默认搜索引擎，支持 Bing、百度、GitHub、BiliBili 和秘塔 AI
2. 搜索词联想与输入法兼容
3. 预设壁纸和自定义壁纸裁切
4. 首页文字自动明暗模式
5. 时间、日期与页脚显示设置
6. Limit ID 登录、头像与偏好云同步
